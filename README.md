## 这是什么

黑武士是一个**长期驻留在你电脑里**的 AI 智能体：

- **持续运行**：不是"打开-聊天-关闭"的窗口，而是有心跳、有作息、能被消息抢占的常驻主循环；
- **真的有内核**：内置 **PASM V2 十九层认知底座**（安全层 / 脑干调质 / 丘脑门控 / 工作记忆 /
  记忆体 / 小脑 / 世界模型 / 情绪 / 岛叶 / 人格 / 元认知 / DMN / 符号层 / 映射 / 执行 / 规划 /
  认知皮层 / narrator），**未接入任何大模型也能运行、记忆、校验、成长**；
- **桌面同源体验**：Electron 壳 + 暗黑科技风 UI，托盘常驻、关窗不退出。

## 为什么要接 PASM：黑武士与白马 AI 的根本分歧

这是本项目最核心的设计判断，先说清楚：

> **白马 AI 的"智能"100% 租自 LLM。** 它的记忆是上下文拼接、它的自主是空闲时问模型一句、
> 它的"自我调节"是提示词里的几行字。模型断了、额度满了、网络挂了，它就哑火；
> 更关键的是——**它不知道自己会错**，也没有任何机制去发现"我这次答偏了"。

PASM 补的是这一块。接入后黑武士获得的不是"更好的回答"，而是**本地就成立的认知器官**：

| 能力 | 白马 AI | 黑武士 + PASM V2 |
|---|---|---|
| 记忆 | 对话历史 / 向量库检索 | 记忆体：模式分离·完成·巩固·再巩固 + **FTS5 中文全文** + 联想线索 |
| 遗忘 | 无，或手动清空 | 艾宾浩斯衰减 + 象量吸引子衰减 + 睡眠重放合并 |
| 情绪 | 无（或仅在提示词里描述） | 杏仁核显著性 + 边缘系统价值 + **四通道神经调质**（多巴胺/血清素/去甲肾上腺素/乙酰胆碱） |
| 注意力 | 无 | **丘脑门控**（相关性筛选 + 新颖度直通，防漏新事物） |
| 自我监控 | 无 | **ACC 元认知**：冲突/错误监测 + 双系统快慢门控（System2 惊讶触发） |
| 反幻觉 | 靠提示词让模型自查（可被绕过） | **三角校验四层**（预测/统计/逻辑/安全）—— 底座级，不依赖模型自觉 |
| 工具安全 | 应用层黑名单（可被绕过） | **内核级安全闸**：白名单/限流/注入筛查/锁死升级，模型绕不过 |
| 自我改进 | 无 | **成长闭环**：失衡告警 → 参数建议 → 灰度应用（`growth_review`） |
| 长期性格 | 无 | 慢时间尺度人格特质 EMA + 成长日记（evalkit 十四项失衡监测） |

### V1 → V2 强在哪，为什么必须上 V2

黑武士 v0.1/v0.2 接的是 PASM **V1**（`pasm_skills`），实际只用到 6 项能力
（记忆/遗忘/巩固/焦点/情绪效价/反馈塑形）—— 说白了只承担了"记忆 + 一点情绪"，
所以那时"为什么接 PASM"其实答不上来。

**V2（`pasm2`，独立包，19 层 + 安全层 + 成长闭环）把它从"一个认知引擎"升级为"认知底座"**：

- V1 = 记忆检索 / 遗忘衰减 / 巩固 / 焦点 / 情绪 / 塑形
- V2 = 上述全部 **+ 安全层（六把锁）**、脑干四通道调质、丘脑门控、工作记忆与前瞻意图、
  小脑时序校正、**世界模型与反事实推理**、岛叶内感受、**ACC 元认知与双系统门控**、
  DMN 自发思考、突显网络、**真符号注册表与符号化梯度**、**三角校验**、SLH 桥与四路路由、
  记忆图（四源边权）、**成长闭环**、evalkit 成长日记

### 这些能力在黑武士里长什么样（不是口号，是可点的界面）

- **「心智」页**：十九层实时活跃度矩阵 —— 情绪值、预测命中/落空、丘脑门控放行/拦下、
  躯体标记、安全层 12 把锁状态、白名单规模、检查/拦截计数、失衡告警列表。
- **对话里看得见**：每次感知都会推 `pasm2_step` 事件，思考流实时显示
  "V2 感知 step 7｜实体#3｜门控放行"。
- **工具调用双闸门**：应用层 policy（配置/风险/频率）之后，还有 V2 安全层
  （白名单/限流/注入/锁死），越界时思考流直接显示"PASM V2 安全层拒绝（safety）：not_in_allowlist"。
- **上下文注入**：模型每轮都能看到 `[PASM V2 认知] 情绪 …｜世界模型 预测落空｜躯体标记 …`。

### 诚实降级（永不做假）

V2 需要 `numpy` + `pasm-agent`，且当前是 `2.0.0a11` 预览版。装了就用真底座，
没装就退回 V1 引擎或内置实现，并在「心智」页与 `/api/mind` **明确标注原因**：

| 档位 | 条件 | 表现 |
|---|---|---|
| `pasm2` | numpy + pasm2 可用 | 十九层真实活跃度、安全层闸门、反事实、成长闭环 |
| `pasm1` | 无 pasm2，有 pasm-skills | 记忆/情绪/焦点（V1 六项），「心智」页标注原因 |
| `builtin` | 都没有 | 内置等价实现，功能完整、语义检索较弱 |

动作类端点在 V2 缺席时返回 **503 + 原因**（不是 500、也不是静默 200）。

## 与同类项目的差异（为什么重复造轮子）

| 能力 | 典型 Electron 桌面 Agent（如白马AI） | 黑武士 |
|---|---|---|
| "智能"来源 | 完全依赖外部 LLM（脑子是租的） | **PASM V2 十九层底座 + LLM 增强**，离线降级不哑火 |
| 记忆 | 对话历史拼接 / 外挂向量库 | **记忆体五机制 + FTS5 中文全文 + 联想线索**，带遗忘曲线 |
| 情绪 | 无 | **四通道神经调质 + 效价/唤醒**，并注入提示词 |
| 世界模型 | 无 | **上下文预测器 + 反事实推理**（`what_if`） |
| 元认知 | 无 | **ACC 冲突/错误监测 + 双系统快慢门控** |
| 焦点 | 无 | **丘脑门控 + 带衰减的话题焦点栈** |
| 反幻觉 | 提示词自查 | **三角校验四层**（底座级）+ 内核级工具安全闸 |
| 自我改进 | 无 | **成长闭环**（失衡告警 → 参数建议）+ 成长日记 |
| 档位诚实度 | 常把降级伪装成正常 | **永不隐藏降级**：`pasm2/pasm1/builtin` 在状态页明示 |
| 自主性 | 空闲轮询 | 8 级心跳决策 + 预测误差缩放 + 提醒独立计时源 |
| 用户画像 | 结构化 profile | 结构化画像 + 启发式/LLM 双抽取 + 置信度与依据 |
| 信息面板 | 天气/热点/人物卡 | 天气/热点/人物卡（未配置诚实降级，不伪造） |
| 预取缓存 | 周期 URL 预热 | 预取登记 + 心跳刷新 + 上下文注入 |
| 工具自发现 | find_tool | find_tool（命中与否都写审计日志，可查"为什么没用那个工具"） |
| 资源感知 | 有 | system_probe（CPU/内存/磁盘/电池，缺 psutil 时如实标注来源） |
| 记忆审计 | 有 | create/update/delete 全量账本（before → after 可追责） |
| 安全 | — | 工具风险三级 + 路径沙箱 + Shell 黑名单 + 局域网强制 Token + **V2 内核安全闸** |
| 媒体/社交/Scene Protocol | 有较长工具面 | **诚实差距（规划中）**：本地媒体处理、社交渠道、Scene Protocol 暂未覆盖 |

黑武士的定位是"参考而非复刻"：借鉴其持续运行架构模式，内核用 Python 重写，
补上它们没有的认知层。

## 快速开始

### 1) 安装内核

```bash
git clone https://gitee.com/arronzheng/BlackWarrior.git
cd BlackWarrior
pip install -e .
# 可选：接入 PASM 真内核（否则用内置等价实现，功能完整、档位标为 light）
pip install -e ".[pasm]"
```

### 2) 启动

```bash
blackwarrior serve           # 浏览器访问 http://127.0.0.1:3721
# 或桌面壳
cd electron && npm install && npm start
```

### 3) 激活（可选）

未接入模型时黑武士**照样运行**：本地内核接管回复、记忆照常累积。
在 UI「接入大脑」弹窗里填入任意 OpenAI 兼容 Key（DeepSeek / Qwen / Kimi / GLM / Ollama…）即解锁完整推理。

### 4) 启用 PASM V2 十九层底座（可选，强烈建议）

```bash
pip install numpy
pip install -e "E:/AI/pasm/code/PASM"     # 提供 pasm2（V2 独立包）
```

装完「心智」页会从"未接入"变成十九层实时活跃度，工具调用也会多一道内核级安全闸。
没装也能用——黑武士会退回 V1 引擎或内置实现，并**明确标注档位**。

### 5) 验证

```bash
blackwarrior selftest        # 包级自检（41 项，纯本地不依赖网络与模型）
python tests/test_server.py  # HTTP/SSE/UI 端到端 + 前端静态一致性（56 项无 V2 / 61 项有 V2）
```

## UI 一览

- **对话流**：异步队列 + SSE 增量渲染，思考条实时显示当前阶段与工具调用；
- **记忆库**：力导向记忆图谱（按保留度着色）、语义检索、一键睡眠巩固；
- **认知内核**（独有）：情绪曲线、预测误差仪表、好奇心、焦点栈、内核快照 JSON；
- **活动**：工具注册表（风险着色）、行动日志、实时事件流；
- **心智**（v0.3 · 独有）：PASM V2 十九层活跃度矩阵、安全层锁与白名单、
  认知计数、失衡告警（"它能发现自己不对劲"）、睡眠巩固与成长复盘按钮；
- **全景**：用户画像卡片、信息面板（天气/热点/人物）、预取缓存登记与管理；
- **设置**：12 家供应商、人格、心跳、能力开关、语音开关，密钥脱敏回显。

## 语音

走浏览器内置 Web Speech API，**零额外依赖**：

| 能力 | 实现 | 可用性 |
|---|---|---|
| 朗读回复（TTS） | `speechSynthesis` | **完全本地、离线可用**，浏览器与桌面壳均支持 |
| 语音输入（ASR） | `SpeechRecognition` | Chromium 走云端识别；**Electron 内置的 Chromium 不带该服务 API key，桌面壳里基本不可用**（按钮自动置灰），在 Chrome / Edge 打开可用 |

要在桌面壳内做真语音输入，需换本地 ASR（whisper.cpp / faster-whisper 之类），
当前版本不引入——能力缺失时一律显式降级并说明原因，绝不静默失效。

## 安全模型

- 默认只监听 `127.0.0.1`；开局域网模式后所有敏感路由强制 Token；
- 工具分 `safe / caution / danger` 三级，策略层可按类别开关 + 频率节流；
- **双闸门**：应用层 policy 之外，PASM V2 安全层在内核侧再拦一道
  （白名单 / 每分钟限流 / 提示注入筛查 / 连续拒绝锁死升级），模型绕不过；
- 文件工具锁定沙箱目录，拒绝 `..` 逃逸；Shell 有黑名单即拒 + 超时上限；
- 配置回显一律脱敏（`key/token/secret/password`）。
